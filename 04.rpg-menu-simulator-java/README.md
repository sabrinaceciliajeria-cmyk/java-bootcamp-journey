# 🎮 RPG Console Simulator

Aplicación de consola desarrollada en **Java** que simula un pequeño juego de rol (RPG), permitiendo al usuario crear un personaje, entrenarlo, combatir contra un enemigo, administrar un inventario y consultar su estado.

Este proyecto tiene como objetivo reforzar el uso de estructuras de control, variables, arreglos y bucles, aplicando los conceptos fundamentales de programación en Java.

---

# 🎯 Objetivos de aprendizaje

Durante este desafío se aplicaron los siguientes conceptos:

- Uso de `Scanner` para la entrada de datos.
- Implementación de un menú interactivo con `do-while`.
- Uso de `switch` para gestionar las opciones del menú.
- Aplicación de `if / else` para validaciones.
- Uso de `while` para el entrenamiento del personaje.
- Uso de `for` para simular la batalla.
- Uso de `foreach` para recorrer el inventario.
- Organización y documentación del código mediante comentarios.

# ⚔️ Funcionalidades

El programa permite realizar las siguientes acciones:

1. Crear un personaje.
2. Entrenar para aumentar vida o fuerza.
3. Simular una batalla contra un enemigo.
4. Visualizar el inventario.
5. Consultar el estado del personaje.
6. Salir del juego.

# 📄 Archivo `.gitignore`

El proyecto incorpora un archivo `.gitignore` para evitar subir archivos temporales o generados automáticamente al repositorio.

Se excluyen elementos como:

- Archivos compilados (`*.class`).
- Archivos de registro (`*.log`).
- Carpetas de compilación (`bin/`, `out/`).
- Configuración del IDE (`.idea/`, `.vscode/`).
- Archivos propios del sistema operativo (`.DS_Store`).

Esto ayuda a mantener un repositorio limpio, organizado y enfocado únicamente en el código fuente.
