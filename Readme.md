# 📚 Fullstack Java Development

## Descripción

Repositorio con ejercicios y mini proyectos del Bootcamp Full Stack Java de Generation Chile. Contiene actividades prácticas organizadas por tema, con código comentado línea por línea y documentación detallada en cada unidad. El objetivo es consolidar competencias en Java, Frontend y algoritmia mediante la práctica estructurada.

---

## 🎯 Cómo funciona

Se irán **agregando nuevas actividades y mini proyectos** de forma progresiva. Cada uno estará ubicado en su **carpeta numerada** (01-, 02-, etc) con su respectivo **README.md** explicando los conceptos, objetivos y pasos de ejecución. A medida que se incorporen nuevas unidades, este documento se irá actualizando.
